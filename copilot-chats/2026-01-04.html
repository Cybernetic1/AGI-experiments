I am thinking of a hopefully more "decisive advantage". An example: human tells LLM, "don't forget to activate venv before running python programs". This can be stored in the prompt as a directive. In current LLMs, thoughts are either in the prompt (working memory) or in the weights (= inference rules). In our architecture, thoughts can be: 1) in WM, 2) in DLN weights, or in the symbolic engine 3) as explicit facts or 4) rules. If we (users) tell an LLM something, it immediately changes behavior because the directive is stored in WM (the prompt). Ideally, we expect a thought to: 1) immediately participate in logic inference, 2) go into memory consolidation in the long term. In an LLM, once the prompt is cleared, the thoughts are forgotten, so its ability to learn from live experience is limited. How might an AGI learn from experience better? A thought in WM does not enter soft memory consolidation, but if it is reflected into a symbolic rule, the symbolic rule can be injected as a neural rule, and participate in further consolidation / generalization / learning. Could this be a significant advantage?
