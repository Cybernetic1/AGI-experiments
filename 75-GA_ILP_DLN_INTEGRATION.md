# GA + ILP + DLN Integration Design

## Current State: Three Powerful Components

### 1. **ILP (Inductive Logic Programming)**
- **What it does:** Mines logical rules from facts using heuristics
- **Algorithms:** Frequency-based, FOIL, Confidence-based
- **Input:** Facts (propositions)
- **Output:** Rules (e.g., `agent(X,Y) ∧ type(Y,Z) → agent_type(X,Z)`)
- **Strength:** Fast, structured, leverages domain knowledge
- **Weakness:** Fixed heuristics, local search

### 2. **GA (Genetic Algorithm)**
- **What it does:** Evolves rules through mutation and crossover
- **Current:** Evolves parsing/generation rules for text↔logic
- **Input:** Dataset + fitness function
- **Output:** Evolved rules with high fitness
- **Strength:** Global search, discovers novel patterns
- **Weakness:** Slow, needs good fitness function

### 3. **DLN (Differentiable Logic Network)**
- **What it does:** Neural network that learns to predict rule conclusions
- **Current:** Trained on labels generated by symbolic rules
- **Input:** Facts (as embeddings)
- **Output:** Truth values for conclusions
- **Strength:** Differentiable, generalizes, fast inference
- **Weakness:** Black box, needs training data

## The Synergies

### Synergy 1: **ILP → DLN** (Current Pipeline)
```
Facts → [ILP mines rules] → Rules → [Apply rules] → Labels → [Train DLN] → Neural Predictor
```
**Status:** ✅ Working now (what you're testing)  
**Benefit:** Fast rule discovery + neural learning  
**Limitation:** ILP uses fixed heuristics

### Synergy 2: **GA → DLN** (Evolution-based Discovery)
```
Dataset → [GA evolves rules] → Fittest Rules → [Apply rules] → Labels → [Train DLN]
                ↑                                                            ↓
                └──────────────── [DLN loss as fitness] ──────────────────┘
```
**Status:** 🔄 Not implemented  
**Benefit:** GA discovers rules DLN can learn from  
**Key:** DLN loss (MSE) becomes GA fitness!

### Synergy 3: **DLN → GA** (Neural-Guided Evolution)
```
[DLN embeddings] → Guide GA mutations → Better rule variations
[DLN gradients] → Highlight useful patterns → Focus GA search
```
**Status:** 🔄 Not implemented  
**Benefit:** Evolution guided by neural representations  
**Novel:** Use neural signals to direct symbolic search

### Synergy 4: **ILP ↔ GA** (Hybrid Search)
```
Facts → [ILP quick mining] → Seed rules → [GA population] → Evolve → Better rules
                                              ↓
                                    [Crossover ILP + GA rules]
```
**Status:** 🔄 Not implemented  
**Benefit:** ILP gives good starting point, GA explores variations  
**Key:** Best of both worlds (structure + exploration)

### Synergy 5: **ILP + GA + DLN** (Full Integration)
```
                    ┌─── ILP (structure) ───┐
                    │                        ↓
Facts → [Quick mining] → Candidate Rules → [GA Refine] → Evolved Rules
                              ↓                              ↓
                         [DLN Evaluate]                [Apply Rules]
                              ↓                              ↓
                         [Loss/Fitness] ──────────→    Train DLN
                              ↑                              ↓
                              └────── [Gradient Signals] ───┘
```

**This creates a feedback loop:**
1. **ILP:** Quickly generates candidate rules (structure)
2. **GA:** Evolves and refines rules (exploration)
3. **DLN:** Evaluates rule quality via loss (differentiable signal)
4. **Feedback:** DLN loss guides both ILP and GA

## Integration Architectures

### Architecture A: **Sequential Pipeline** (Simplest)
```python
# Phase 1: ILP discovers initial rules
ilp_rules = mine_frequency_based(facts, max_rules=50)

# Phase 2: GA refines rules
ga_rules = genetic_algorithm(
    initial_population=ilp_rules,
    fitness_fn=lambda r: evaluate_with_dln(r, facts),
    generations=50
)

# Phase 3: Train DLN on best rules
best_rules = select_top_k(ga_rules, k=20)
train_dln(dln_model, best_rules, facts)
```

**Pros:** Simple, clear stages  
**Cons:** No continuous feedback

### Architecture B: **Co-Evolution** (Moderate)
```python
# Initialize
ilp_rules = mine_frequency_based(facts, max_rules=30)
ga_population = ilp_rules + [mutate(r) for r in ilp_rules]
dln_model = SimpleDLN(...)

for generation in range(100):
    # Evaluate rules using DLN
    for rule in ga_population:
        labels = apply_rule(rule, facts)
        loss = train_dln_on_labels(dln_model, labels)
        rule.fitness = -loss  # Lower loss = higher fitness
    
    # Evolve rules
    ga_population = evolve(ga_population)
    
    # Periodically inject new ILP rules
    if generation % 10 == 0:
        fresh_rules = mine_foil_style(facts, max_rules=5)
        ga_population += fresh_rules
```

**Pros:** Continuous feedback, co-evolution  
**Cons:** More complex

### Architecture C: **Neural-Guided ILP** (Advanced)
```python
# Use DLN embeddings to guide ILP mining
dln_model = SimpleDLN(...)

# Phase 1: Train DLN on initial ILP rules
ilp_rules = mine_confidence_based(facts, max_rules=30)
train_dln(dln_model, ilp_rules, facts)

# Phase 2: Use DLN to score potential rules
for candidate_rule in generate_all_possible_rules(facts):
    # Use DLN to predict rule quality (fast!)
    quality_score = dln_model.evaluate_rule(candidate_rule)
    
    if quality_score > threshold:
        accept_rule(candidate_rule)

# Phase 3: GA evolves accepted rules
ga_rules = genetic_algorithm(
    initial_population=accepted_rules,
    fitness_fn=lambda r: dln_model.evaluate_rule(r)
)
```

**Pros:** DLN accelerates search (no symbolic inference needed)  
**Cons:** Requires DLN to learn rule quality prediction

## Key Design Decisions

### Decision 1: Fitness Function
**Option A:** DLN loss (differentiable, accurate)
```python
fitness = -train_dln_and_get_loss(rule, facts)
```

**Option B:** Coverage + Consistency (symbolic, fast)
```python
fitness = num_facts_matched(rule, facts) * consistency_score(rule)
```

**Recommendation:** Start with B (fast), move to A (accurate)

### Decision 2: Population Seeding
**Option A:** Pure ILP seed
```python
population = ilp_rules + [random_rule() for _ in range(50)]
```

**Option B:** Mixed seed
```python
population = frequency_rules + foil_rules + confidence_rules + random
```

**Recommendation:** Option B (diversity)

### Decision 3: Integration Timing
**Option A:** Offline (ILP → GA → DLN sequentially)
```python
rules = ilp_then_ga(facts)
dln = train_dln(rules, facts)
```

**Option B:** Online (continuous co-evolution)
```python
for step in range(1000):
    rules = evolve(rules, dln.loss)
    dln.train_step(rules, facts)
```

**Recommendation:** Start with A (simpler), evolve to B
