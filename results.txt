----------------------------------------------------------------------
  Task: Binary classification (fact true/false)
  Input: 3 premises + 1 conclusion (4 props × 48 dim)
  Output: Probability (1 dim)
  Training: Binary cross-entropy on labels
  Data: Random fact triples
  DLN config: 2+ rules, 3 premises, 4 var_slots
  Total params: 59K+ (10× larger than TTT!)
  Result: Stuck at 50% (random guessing)

----------------------------------------------------------------------
KEY DIFFERENCES:
----------------------------------------------------------------------
  1. Task complexity:
     TTT: Sequential, grounded in physical board
     TinyStories: Abstract logical inference

  2. Input representation:
     TTT: Direct board encoding (hand-crafted features)
     TinyStories: Learned embeddings → might be poor

  3. Training signal:
     TTT: Strong (win/loss + AR reconstruction)
     TinyStories: Weak (single binary label)

  4. Data quality:
     TTT: Clean game trajectories
     TinyStories: Noisy fact triples + synthetic negatives

  5. Parameter scale:
     TTT: 4.7K params (appropriate for task)
     TinyStories: 59K+ params (might be over-parameterized)

======================================================================
LEARNING FAILURE DIAGNOSTICS
======================================================================

Possible causes:

1. POOR EMBEDDINGS
   - TinyStories uses learned embeddings (16-dim)
   - Embeddings might not capture semantic meaning
   - DLN tries to learn logic over meaningless vectors
   → Test: Use pre-trained embeddings or one-hot (but smaller vocab)

2. WRONG TASK FORMULATION
   - Binary classification too simple for DLN
   - DLN designed for sequential/structured reasoning
   - No temporal or causal structure in our data
   → Test: Use autoregressive task like TTT

3. INSUFFICIENT TRAINING SIGNAL
   - Each example only provides 1 bit of information (true/false)
   - Synthetic negatives might be too random
   - No reward shaping or intermediate supervision
   → Test: Add auxiliary tasks or multi-task learning

4. ARCHITECTURE MISMATCH
   - Proposition format might not match what DLN expects
   - 3 premises + 1 conclusion might not provide enough context
   - Variable binding might not be needed for this task
   → Test: Vary num_premises, var_slots

5. HYPERPARAMETER ISSUES
   - Learning rate (0.001 might be wrong)
   - Batch size (1 example at a time vs batches)
   - Loss function (BCE might not work well)
   → Test: Grid search hyperparameters
